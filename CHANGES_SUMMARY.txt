STANDARDIZED AGENT RESULT CONTRACT
═══════════════════════════════════════════════════════════════════════════════

All agents (Billing, Payment, Plans, Technical, General) now return:

{
  "agent": "billing|plans|payment|technical|general",
  "response": "string (user-facing response)",
  "success": bool (operation success),
  "confidence": float (0.0-1.0),
  "tool_used": "string or None",
  "tool_result": "dict or None",
  "rag_context": "dict or None",
  "requires_customer_id": bool ← NEW SIGNAL
}

This standardization enables:
✓ Consistent orchestrator processing
✓ Unified error handling
✓ Customer ID signal detection
✓ Proper pending state management
